# School Manager 1.7

Дата релізу: 20 травня 2026

## Коротко

Версія 1.7 зосереджена на зручності щоденної роботи з повідомленнями: наліпки, шаблони, Telegram-форматування, автоповідомлення та безпечніше очищення кешу. Головна ідея релізу: менше випадкових втрат, більше поведінки як у Telegram, швидше створення готових повідомлень.

## Нове

- Додано наліпки до шаблонів повідомлень.
- Шаблони тепер можуть містити текст, файли та наліпки одночасно.
- Наліпки з шаблону вставляються у звичайні повідомлення та автоповідомлення.
- Додано Telegram-форматування для повідомлень, автоповідомлень і шаблонів.
- Форматування тепер відображається одразу в полі вводу: жирний, курсив, підкреслений, закреслений, цитата, моноширинний текст, спойлер, посилання, дата.
- Додано праве меню форматування для виділеного тексту.
- Додано швидкі кнопки форматування біля кнопок emoji та наліпок.
- В автоповідомленнях час можна вводити вручну з клавіатури, наприклад `2135` або `21:35`.
- Кількість повторів в автоповідомленнях можна змінювати стрілками клавіатури та колесом миші, коли поле активне.
- Контейнер версії програми на головній сторінці відкриває вкладку `Інфо`.

## Виправлено

- Вікно наліпок більше не стискається під час скролу сторінки.
- Вікно наліпок відкривається стабільно, поводиться ближче до вікна смайликів і не обрізає останні рядки.
- Виправлено відкриття наліпок у модальному вікні шаблонів.
- Очищення кешу програми більше не видаляє наліпки.
- Очищення наліпок винесено в окрему дію, щоб випадково не змусити програму заново довго завантажувати весь sticker cache.
- Кнопки очищення кешу та наліпок розділено візуально: небезпечна дія для кешу виділена червоним, наліпки мають окрему менш агресивну кнопку.

## Технічні зміни

- Версію програми оновлено до `1.7`.
- Додано збереження наліпок у шаблонах на рівні бази та API.
- Додано окремий backend endpoint для очищення кешу наліпок.
- Додано rich-editor для Telegram-повідомлень із конвертацією у Telegram-сумісну розмітку перед відправкою.
- Покращено позиціонування floating panels для великих попапів.

## Перевірено

- Збірка фронтенду проходить через `npm run build`.
- Backend-файли компілюються через `python -m py_compile`.
- Основні сценарії перевірені в браузері: повідомлення, автоповідомлення, шаблони, налаштування, сторінка інфо.
