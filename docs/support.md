# Support Guide

Цей файл потрібен для швидкого розбору проблем користувача.

## Що попросити у користувача

1. Версію програми.
2. ОС: Windows або macOS, версія системи.
3. Що саме робив користувач перед помилкою.
4. Скріншот або коротке відео.
5. Diagnostic log з програми.

## Як користувачу зберегти log-файл

У програмі:

```text
Налаштування -> Зберегти log файл
```

Програма відкриє системне вікно збереження файлу. Користувач вибирає папку і надсилає `.txt` файл у підтримку.

Diagnostic log містить:

- версію програми;
- платформу;
- шлях до runtime-папки;
- розмір бази і кешів;
- кількість основних записів у базі;
- останні події з журналу програми;
- launcher/backend logs.

Відомі секрети мають редагуватися автоматично, але якщо log пересилається далі, його все одно варто переглянути.

## Runtime-папки

Windows:

```text
%LOCALAPPDATA%\SchoolManager
```

macOS:

```text
~/Library/Application Support/SchoolManager
```

Там можуть бути:

- `school_manager.db`
- Telegram session
- `launcher.log`
- `error_backend.log`
- `template_files/`
- `auto_message_files/`
- `import_cache/`
- `sticker_cache/`

## Типові проблеми

### Програма не запускається

Попросити:

- `error_backend.log`
- `launcher.log`
- diagnostic log, якщо програма встигає відкритися

Перевірити:

- порт `127.0.0.1:8001`;
- чи не запущена стара копія;
- чи не заблокував антивірус;
- чи є права на runtime-папку.

### Telegram не авторизується

Перевірити:

- чи правильно введений номер;
- чи Telegram не вимагає 2FA;
- чи session-файл не пошкоджений;
- чи немає flood/limit помилок у журналі.

### Повідомлення не відправляються

Перевірити:

- чи Telegram акаунт підключений;
- чи групи синхронізовані;
- чи група доступна акаунту;
- чи файли не занадто великі;
- чи немає помилок Telegram у `Журнал подій`.

### Google AI не генерує

Перевірити:

- чи доданий Google AI API key;
- чи вибрана модель;
- чи не вичерпано ліміти AI Studio;
- чи є помилки у `Журнал подій`.

Корисні кнопки в програмі:

- `API key`
- `Ліміти AI Studio`

### Звіти батькам не з'являються

Перевірити:

- день і час уроку;
- тривалість уроку;
- дату останнього звіту;
- чи не перенесений урок;
- чи прив'язана Telegram-група;
- чи є дані уроку з online-бази звітів.

### Автозапуск не працює

Windows:

- перевірити `Налаштування -> Автозапуск`;
- перевірити Task Manager -> Startup apps;
- перевірити registry `CurrentVersion\Run`;
- після видалення програми autostart має чиститися uninstall-скриптом.

macOS:

- перевірити LaunchAgent;
- перевірити runtime logs;
- якщо tray недоступний, програма має відкритися звичайним вікном і записати причину в log.

## Перед тим як просити користувача перевстановити

1. Спробувати закрити програму через tray.
2. Перезапустити ПК.
3. Зберегти diagnostic log.
4. Перевірити оновлення.
5. Якщо треба повністю очистити дані, попередити, що буде втрачено локальну базу, Telegram session, шаблони і кеші.
