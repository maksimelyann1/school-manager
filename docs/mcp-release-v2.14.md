# Перевірка MCP для релізу v2.14

Переглянуто чат «Інтегрувати Codex зі school_manager»
(`01a16966-7504-7d02-97d3-75623e787454`), документацію та фактичні локальні файли.
Каталог `mcp-tools.json` регенеровано з 93 реально зареєстрованих команд.

MCP використовує loopback HTTP API. Доданий router асистента читає стан,
контекст курсу та локальні свідчення про звіти. Звіти, автозвіти й розсилки
викликають наявні маршрути; логіка їх надсилання не скопійована в MCP.
Помилки й тайм-аути не спричиняють автоматичних повторних відправлень.

Файли `parents_report.py`, `auto_messages.py`, `report_delivery.py`, `models.py`,
`database.py`, `services/planner/reminders.py`, `desktop_app.py` та
`desktop_widgets.py` не змінені відносно V2.13. Нових моделей, міграцій або
змін інтерфейсу немає. П'ять виключень з `mcp-implementation.md` збережено.

Перевірки перед публікацією:

- 282 Python-тести програми та 39 тестів MCP успішні.
- Наскрізний STDIO MCP → HTTP → тимчасова база: 93 команди в handshake;
  годинна подія, одне нагадування без дубля, відхилення старої revision,
  п'ять станів звітів, шаблони й вкладення, налаштування промпту, курси,
  розклад, імітована штатна відправка звіту та відхилення дубля.
- Реальних повідомлень — 0; тестовий планувальник не запускався.
- 83 HTTP-виклики з фіксованими або форматованими маршрутами звірено з
  фактичними маршрутами й HTTP-методами backend: розбіжностей немає.
- 3 нові тести чистоти артефактів і 14 JavaScript-тестів успішні;
  інтерфейс зібрано, перевірка запуску підтверджує v2.14.

Окремий архів `SchoolManager-Codex-MCP.zip` формується GitHub Actions через
`git archive` лише з відстежуваних вихідних файлів і документації.
Залежності MCP не додані до `backend/requirements.txt`; Python-середовище MCP
не включається в EXE. Перевірка артефактів відхиляє також `.venv`, `venv`,
`backups`, `output` і `tmp`.

Порядок: встановити v2.14, запустити потрібну копію School Manager, розпакувати
MCP у постійну папку й виконати `setup.ps1 -Register` за README, перезапустити
Codex, перевірити `get_status` (version=2.14, runtime=installed).
Якщо MCP вже підключений до цієї папки проєкту, достатньо оновлення програми
та перезапуску Codex. Для підключення з іншої папки потрібно повторити реєстрацію.

Живі Google/Telegram/Logika та встановлення на ПК користувача цими тестами
не підтверджені. Системні нагадування потребують запущеної програми та
ввімкнених сповіщень. Повний опис обмежень — у `mcp-implementation.md`.
